# Java Wrapper Class and Collections Programs

Java programs covering Wrapper Classes and Collection Framework concepts.

## Programs

| File | Topic |
|------|-------|
| P01_Boxing | Auto-boxing and manual boxing for all primitive types |
| P02_Unboxing | Auto-unboxing in assignments, arithmetic, loops + NPE pitfall |
| P03_Parsing | String to primitive using parseInt, parseDouble, parseLong, etc. |
| P04_Unparsing | Primitive to String using toString(), String.valueOf(), concatenation |
| P05_ListCollection | ArrayList + LinkedList - add, remove, sort, iterate |
| P06_SetCollection | HashSet (unordered), LinkedHashSet (insertion order), TreeSet (sorted) |
| P07_QueueCollection | Queue (FIFO), PriorityQueue (min heap), ArrayDeque (double-ended) |
| P08_MapCollection | HashMap, LinkedHashMap, TreeMap - CRUD + iteration |
| P09_CollectionsPractical | Student Grade Management using ArrayList, HashMap, HashSet, PriorityQueue, LinkedList |
