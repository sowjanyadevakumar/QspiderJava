# Java Exception Handling Programs

Java programs covering Exception & Exception Handling concepts.

| P02_ExceptionHierarchy | Catching at different levels: RuntimeException, Exception, Throwable |
| P03_TypesOfException | Checked vs Unchecked exceptions |
| P04_ImportantExceptions | NullPointerException, ArrayIndexOutOfBounds, ClassCast, ArithmeticException, NumberFormat, StringIndexOutOfBounds, ArrayStore |
| P05_ErrorAndAdvantage | StackOverflowError + advantage of exception handling |
| P06_TryCatch | Basic try-catch, nested try-catch |
| P07_MultiCatch | Multiple catch blocks + combined catch (Java 7+) |
| P08_FinallyBlock | Finally with and without exception, finally with return |
| P09_TryWithResources | AutoCloseable, single and multiple resources |
| P10_ThrowAndPropagation | throw keyword + exception propagation |
| P11_ProgramOnException | Bank Account program: custom exception + validation |
| P12_CustomExceptionAndThrowVsThrows | Custom checked/unchecked exceptions + throw vs throws |
